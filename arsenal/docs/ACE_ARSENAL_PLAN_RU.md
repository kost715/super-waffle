# Перевод арсенала на ACE Arsenal — план (отложено)

Статус: только проработка, не реализовано. Сохранено 2026-10-30 по итогам обсуждения.
Источник по API: https://ace3.acemod.org/wiki/framework/arsenal-framework

## Главная сложность
В ACE Arsenal нет количества: предметы в ящике бесконечные. Учёт склада в нашем моде
уже ведёт сервер (снимок при открытии, сверка при закрытии), окну он не нужен.

## Схема
1. Открытие: сервер, как сейчас, присылает разрешённые предметы со склада. Клиент
   добавляет их ящику локально (`ace_arsenal_fnc_addVirtualItems`, global = false),
   поэтому у каждого игрока свой список по его правам, затем вызывает
   `ace_arsenal_fnc_openBox`.
2. Счётчики в названиях: событие `ace_arsenal_leftPanelFilled`.
3. Лимит во время выбора: событие `ace_arsenal_itemsChanged` (взятое и возвращённое по
   классам). Кончившийся предмет убирается `ace_arsenal_fnc_removeVirtualItems` +
   `ace_arsenal_fnc_refresh`. Нужна свежая версия ACE.
4. Закрытие: `ace_arsenal_displayClosed` → текущий `requestClose` с `getUnitLoadout`.
   Защита от подделок и рассинхрона остаётся серверной, как сейчас.
5. Готовые наборы и импорт ACE проверяются сервером при закрытии.

## Без изменений
Склады и сохранение, права по сторонам, порог «бесконечности», отладка, модуль Зевса
«Склад арсенала», файл склада, модуль Eden и атрибут Storage ID.

## Что меняется
- Кнопка «Из ящика» станет отдельным действием на ящике.
- Режима «арсенал для техники» в ACE нет: оставить на окне JNA или убрать.
- Обновление чужих открытых окон в реальном времени — только по сигналу сервера,
  проверить в игре.
- Если убирать окно BIS совсем, ACE станет обязательной зависимостью.

## Предложение
Настройка CBA «Интерфейс арсенала: ACE / BIS», ACE по умолчанию при загруженном ACE.

## Открытые вопросы к пользователю
1. Переключатель ACE/BIS или только ACE?
2. Арсенал для техники: оставить на окне JNA или убрать?
3. Версия ACE (нужна для `ace_arsenal_itemsChanged`).
4. Если игрок взял больше остатка (например, загрузкой набора): откат всего снаряжения
   (как сейчас) или снятие только лишнего?
