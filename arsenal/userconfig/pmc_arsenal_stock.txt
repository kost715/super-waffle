// PMC Arsenal: редактируемый склад.
//
// Куда положить (сервер читает первый найденный):
//   1) <папка Arma 3>\userconfig\pmc_arsenal_stock.txt — если сервер запущен с -filePatching;
//   2) pmc_arsenal_stock.txt в корне папки миссии.
//
// Как работает: после рестарта миссии сервер один раз применяет изменённый файл.
// Каждое хранилище из списка получает ровно указанный склад; хранилища, которых
// нет в списке, не меняются. Пока файл не меняли, он больше не применяется, и всё,
// что игроки взяли или сдали, сохраняется как обычно.
//
// Строки склада:
//   ["класс", штук]                  — оружие, предметы, рюкзаки
//   ["класс", магазинов]             — магазины
//   ["класс", магазинов, патронов]   — магазины плюс неполный остаток в патронах
//   -1 вместо количества             — бесконечно
// Классы пишутся как в конфиге игры. Проще всего взять их из выгрузки склада:
// текущий склад сервер пишет в RPT в конце каждой миссии в этом же формате
// (между строками "stock file begins" и "stock file ends"): его можно скопировать сюда.
//
// Пример (уберите // в начале строк, чтобы он заработал):
// [
//     ["base", [
//         ["arifle_MX_F", 10],
//         ["30Rnd_65x39_caseless_mag", 40],
//         ["30Rnd_65x39_caseless_mag_Tracer", 5, 12],
//         ["FirstAidKit", -1],
//         ["B_AssaultPack_rgr", 3]
//     ]],
//     ["depot", [
//         ["launch_RPG32_F", 2]
//     ]]
// ]
