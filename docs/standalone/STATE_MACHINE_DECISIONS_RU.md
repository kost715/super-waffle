# Стейт-машина сторон: разбор Override GDD и решения

Дата: 27 октября 2026 года. Исходный документ пользователя сохранён без изменений:
[OVERRIDE_GDD_STATE_MACHINE_RU.md](OVERRIDE_GDD_STATE_MACHINE_RU.md).
Разбор выполнил Claude. Документ Override заменяет модель F2 «синяя ЧВК всегда WEST,
красная всегда EAST»: игроки и их ИИ по умолчанию гражданские, боевая сторона
назначается динамически по контракту, зоне и правилам маскировки.

## 1. Ограничения движка, на которых строится реализация

| Требование документа | Как это работает в Arma 3 |
| --- | --- |
| «Перекрасить» юнит или отряд | Сторона юнита — сторона его группы. Сменить её можно только переносом юнитов в новую группу нужной стороны (`createGroup` + `joinSilent`). Поэтому каждый игрок — в своей группе. |
| «Гражданский» статус и маскировка | Два способа: группа стороны CIV или флаг пленного (`setCaptive`, так делает Antistasi). Стенд S2 позволяет сравнить оба. ACE ставит этот флаг потерявшим сознание и связанным — с ACE нужно использовать его API. |
| «Локальные» отношения в зоне | Отношения сторон (`setFriend`) глобальны на всю карту. **Таблица сторон задаётся один раз и больше не меняется.** «Локальное» — только перенос групп и флаг пленного. |
| «Урон заблокирован» у союзников и нейтралов | Движок управляет лишь решением ИИ стрелять. Игрок может поразить кого угодно. Урон не блокируется, а становится событием стейт-машины (иначе не сработает триггер из п. 4.1). |
| Огонь по «своим» | Снижает rating; ниже −2000 юнит становится изгоем для всех. На юнитах ЧВК rating фиксируется (`HandleRating`), им управляет стейт-машина. |

Риски, требующие игровой проверки: задержка, с которой ИИ замечает новую сторону
цели; сброс приказов ботов при переносе в другую группу; возрождение и каналы,
привязанные к стороне; лимит 288 групп на сторону; переключения на границе зоны.

## 2. Решения пользователя

От 27 октября 2026 года:

1. **WEST и EAST — всегда союзники.** Правительство и корпорации в бою — одна
   коалиция; GUER враждебны обоим; CIV дружественны всем. Таблица сторон
   задаётся при старте и не меняется.
2. **Локальная перекраска — только для отрядов** (групп), а не для отношений
   сторон в зоне.
3. **«Урон заблокирован» в матрице — опечатка.** С и Н означают: у ИИ нет
   намерения стрелять. Урон движком не блокируется; попадание по союзнику или
   нейтралу — событие для стейт-машины.
4. **Основной способ маскировки — перевод в CIV.** Он позволяет в редких случаях
   применить к отдельному гражданскому юниту механику изгоя (rating ниже −2000).
   Флаг пленного остаётся для отдельных сложных сценариев (раздел 3).
5. **Зона банды — зона снятия маскировки.** Замаскированная ЧВК, вошедшая в зону
   контроля банды (её база, подход к укрытию), демаскируется в боевой цвет.
6. **Атака базы: атакующий — GUER, обороняющийся — EAST.** Базовый алгоритм;
   доработать при реализации баз.

Следствия для матрицы Override:

- Колонка и строка 7 («ЧВК за красных» ↔ Правительство) — **С**, а не **В**.
- Сепаратисты, перекрашенные в EAST для боя с бандами (п. 4.3), на это время
  союзники правительства. Если это нежелательно — отдельное правило для
  правительственных сил в такой зоне (например, флаг пленного у полиции).
- Демаскировка в зоне банды: цвет по правилу блокпоста 4.4 — без контракта WEST,
  на корпоративном задании EAST. Оба враждебны GUER, поэтому банда атакует.
- Гарнизон базы ЧВК в покое — CIV; при атаке периметра — EAST (оборона),
  атакующие — GUER. Правительство (WEST) союзно обороне.

## 3. Маскировка: перевод в CIV или флаг пленного

### Сравнение

| Критерий | Перевод группы в CIV | Флаг пленного (`setCaptive`) |
| --- | --- | --- |
| Уровень | Вся группа (сторона — свойство группы) | Каждый юнит отдельно |
| Что видит движок | Настоящая сторона CIV, отношения из таблицы | Боевая сторона сохраняется, но юнит не считается целью |
| Приказы ботов | Сбрасываются при каждом переносе в новую группу | Сохраняются |
| Скорость | Перенос на сервере + репликация группы | Мгновенно, но ставится там, где юнит локален |
| Стреляет ли сам | Нет: CIV ни с кем не враждует | **Да**: боты-«пленные» могут стрелять по врагам, оставаясь невидимыми — нужен отдельный запрет |
| `side unit` | CIV | Тоже CIV (у пленного), `side group` — боевая; скрипты должны различать |
| Изгой точечно | Да: rating ниже −2000 у одного юнита | Не сочетается: пленного не атакуют даже изгоем |
| ACE | Не конфликтует | ACE сам ставит флаг (без сознания, наручники) через счётчик причин; нужен его API, иначе снятие флага ACE «рассекретит» юнит |
| Возрождение, каналы, метки стороны | Привязаны к стороне: нужны маркер `respawn_civilian` и свой интерфейс | Без изменений |
| Лимит 288 групп на сторону | Расходует группы при частых сменах | Не расходует |

### Предложение: гибрид

- **Перевод в CIV** — основной путь для групп игроков: тыл ↔ контракт ↔ аура.
  Смены редкие (вход и выход из зоны, конец ауры), поэтому сброс приказов
  ботов терпим, а поведение предсказуемо.
- **Флаг пленного** — только для случаев, где перенос группы вреден:
  1. ACE: без сознания и в наручниках — через API ACE со своей причиной;
  2. «слепое пятно» полиции в зоне корпоративного PvP (п. 4.1): полиция
     не теряет приказы, флаг снимается при уроне от ЧВК;
  3. гарнизон базы в покое, если окажется, что смена стороны мешает его
     постам (решение — по результатам стенда);
  4. отдельные юниты, которые нельзя переносить вместе с группой
     (например, бот, отставший от отряда, — вопрос TBD документа).
- **Изгой** — точечно для гражданского юнита-нарушителя. Только для юнита без
  ботов или вынесенного в отдельную группу: члены его группы тоже начнут по нему
  стрелять.

### Проблемы чистого перевода в CIV и решения

| Проблема | Решение |
| --- | --- |
| Сброс приказов, строя, режима боя у ботов | Хранить их в записи игрока, восстанавливать после переноса; боты получают `doFollow` лидера |
| ИИ помнит прежнюю сторону цели («воспринимаемая сторона») | `forgetTarget` и `reveal` для ИИ рядом после каждой смены; время реакции измеряет стенд S2 |
| «Первый выстрел» из маскировки: CIV стреляет, а ИИ ещё считает его своим | Демаскировка по событию выстрела сразу, не дожидаясь секундного тика |
| Смешанный экипаж: в одной машине группы разных цветов | Сторона машины — сторона командира. Правило: в машине все получают самый «боевой» цвет из экипажа |
| Привязка к стороне: возрождение, канал «Сторона», метки | Маркер `respawn_civilian` и маркеры всех сторон в лагере; свой чат и метки ЧВК; в коде везде `side group`, не `playerSide` |
| Убийство «союзника» снижает rating | `HandleRating` на юнитах ЧВК; rating меняет только стейт-машина |
| Расход групп | Пустые группы удаляются; для 16 игроков лимит 288 недостижим |
| Задержка репликации группы у поздно вошедших | Состояние в публичных переменных группы; сервер — единственный источник |

Стенд S2 позволяет переключать оба способа и сравнить их в игре: время реакции,
задержку прекращения огня, поведение ботов.

## 5. Архитектура

- **Неизменная таблица сторон** при старте: WEST↔EAST союз, WEST/EAST↔GUER вражда,
  CIV дружественна всем.
- **Состояние группы игрока** вычисляется на сервере чистой функцией и
  применяется только при изменении. Приоритет:

| Приоритет | Состояние | Сторона | Флаг пленного | Когда |
| --- | --- | --- | --- | --- |
| 1 | Без сознания / связан (позже, ACE) | не меняется | да | события ACE |
| 2 | Преступник (позже) | GUER на всей карте | нет | нарушение в тылу |
| 3 | Контракт в зоне БД | по контракту WEST / EAST / GUER | нет | вход в зону |
| 4 | Аура | последний боевой цвет | нет | 5 минут после выхода или демаскировки |
| 5 | Тыл (маскировка) | CIV (основной способ) | нет | по умолчанию |

- Демаскировка: выстрел из группы в тылу, вход в зону контроля банды; позже —
  снаряжение, вооружённая техника, блокпосты, урон. Цвет — по контракту,
  без контракта WEST (п. 4.4).
- Перекраска: сервер переносит всю группу (игрок первым, остаётся лидером) в новую
  группу нужной стороны; флаг пленного ставится на машине-владельце юнита.
- После смены ближайшие ИИ могут сбрасывать знания о группе (`forgetTarget` и
  `reveal`), чтобы сразу пересчитать её сторону. В стенде это переключатель.
