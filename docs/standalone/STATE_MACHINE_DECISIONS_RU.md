# Стейт-машина сторон: разбор Override GDD и решения

Дата: 27 октября 2026 года. Исходный документ пользователя сохранён без изменений:
[OVERRIDE_GDD_STATE_MACHINE_RU.md](OVERRIDE_GDD_STATE_MACHINE_RU.md).
Разбор выполнил Claude. Документ Override заменяет модель F2 «синяя ЧВК всегда WEST,
красная всегда EAST»: игроки и их ИИ по умолчанию гражданские, боевая сторона
назначается динамически по контракту, зоне и правилам маскировки.

## 1. Ограничения движка, на которых строится реализация

| Требование документа | Как это работает в Arma 3 |
| --- | --- |
| «Перекрасить» юнит или отряд | Сторона юнита — сторона его группы. Сменить её можно только переносом юнитов в новую группу нужной стороны (`createGroup` + `joinSilent`). Поэтому каждый игрок — в своей группе. |
| «Гражданский» статус и маскировка | Два способа: группа стороны CIV или флаг пленного (`setCaptive`, так делает Antistasi). Стенд S2 позволяет сравнить оба. ACE ставит этот флаг потерявшим сознание и связанным — с ACE нужно использовать его API. |
| «Локальные» отношения в зоне | Отношения сторон (`setFriend`) глобальны на всю карту. **Таблица сторон задаётся один раз и больше не меняется.** «Локальное» — только перенос групп и флаг пленного. |
| «Урон заблокирован» у союзников и нейтралов | Движок управляет лишь решением ИИ стрелять. Игрок может поразить кого угодно. Урон не блокируется, а становится событием стейт-машины (иначе не сработает триггер из п. 4.1). |
| Огонь по «своим» | Снижает rating; ниже −2000 юнит становится изгоем для всех. На юнитах ЧВК rating фиксируется (`HandleRating`), им управляет стейт-машина. |

Риски, требующие игровой проверки: задержка, с которой ИИ замечает новую сторону
цели; сброс приказов ботов при переносе в другую группу; возрождение и каналы,
привязанные к стороне; лимит 288 групп на сторону; переключения на границе зоны.

## 2. Решения пользователя

- **WEST и EAST — союзники** (решение от 27 октября 2026 года). Правительство и
  корпорации в бою — одна коалиция «закона и бизнеса»; GUER враждебны обоим;
  CIV дружественны всем.

Следствия, которые нужно внести в матрицу Override:

1. Колонка 7 и строка 7 («ЧВК: выход за красных» ↔ Правительство) должны стать
   **С**, а не **В**: обе стороны — одна пара WEST↔EAST.
2. Сепаратисты, перекрашенные в EAST для боя с бандами (п. 4.3), на это время
   становятся союзниками правительства. Если это нежелательно, им нужен другой
   приём (например, флаг пленного для правительственных сил в этой зоне).

## 3. Открытые вопросы

- Банды против замаскированной ЧВК («В/Н по зоне»): банды не могут быть врагами
  стороны CIV (они начнут убивать всех мирных). Предложение: в зоне банд ЧВК
  демаскируется в контекстный цвет по правилу блокпоста 4.4.
- «База зеленеет при атаке» (раздел 5): GUER — вне закона, правительство начнёт
  атаковать защитников. Возможно, имелся в виду боевой цвет владельца.
- Документы F2 (`DEVELOPMENT_DIRECTION_RU.md`, `FACTIONS_AND_SETUP_RU.md`,
  `ROADMAP_RU.md`) и `AGENTS.md` нужно согласовать с Override после стенда S2.

## 4. Архитектура

- **Неизменная таблица сторон** при старте: WEST↔EAST союз, WEST/EAST↔GUER вражда,
  CIV дружественна всем.
- **Состояние группы игрока** вычисляется на сервере чистой функцией и
  применяется только при изменении. Приоритет:

| Приоритет | Состояние | Сторона | Флаг пленного | Когда |
| --- | --- | --- | --- | --- |
| 1 | Без сознания / связан (позже, ACE) | не меняется | да | события ACE |
| 2 | Преступник (позже) | GUER на всей карте | нет | нарушение в тылу |
| 3 | Контракт в зоне БД | по контракту WEST / EAST / GUER | нет | вход в зону |
| 4 | Аура | последний боевой цвет | нет | 5 минут после выхода или демаскировки |
| 5 | Тыл (маскировка) | CIV, либо прежняя сторона с флагом пленного | нет / да | по умолчанию |

- Демаскировка: выстрел из группы в тылу; позже — снаряжение, вооружённая техника,
  блокпосты, урон. Цвет — по контракту, без контракта WEST (п. 4.4).
- Перекраска: сервер переносит всю группу (игрок первым, остаётся лидером) в новую
  группу нужной стороны; флаг пленного ставится на машине-владельце юнита.
- После смены ближайшие ИИ могут сбрасывать знания о группе (`forgetTarget` и
  `reveal`), чтобы сразу пересчитать её сторону. В стенде это переключатель.
