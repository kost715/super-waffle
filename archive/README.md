# Архив — больше не используется в активной разработке

Эти материалы сохранены для истории, сравнения и чтения прежних решений.
Текущий проект развивается самостоятельно, без обязательной зависимости от LifeSim.
Актуальные правила: [вектор развития](../docs/standalone/DEVELOPMENT_DIRECTION_RU.md).

| Каталог | Что сохранено | Статус |
| --- | --- | --- |
| [lifesim-pmc-unused](lifesim-pmc-unused/STATUS_RU.md) | Прежний аддон, все версии сборок, исходный архив 0.6.3, инструменты, проверки, планы и два аудита | Больше не используется как основа режима |
| [standalone-planning-v1-unused](standalone-planning-v1-unused/README.md) | Первая концепция самостоятельного проекта на 1–3 ЧВК, PDF и материалы S0 | Заменена правилами ровно двух компаний |

Исходные файлы прежнего репозитория сохранены без изменения содержимого.
Перечень 147 файлов и SHA-256: [PRESERVATION.json](PRESERVATION.json).
История коммитов также сохранена; коммиты с аудитами включены в текущую ветку.

Старые README, даты, номера версий и инструкции внутри архива описывают своё время.
Указание «текущая версия» в архивном документе не определяет версию активного проекта.
Архив не подключается к сборке самостоятельного мода. Документы прежней экономики
остаются источником требований только в части, перенесённой в актуальный вектор.
