# LifeSim PMC

Опциональный аддон управления ЧВК для Arma LifeSim. Текущий выпуск — **0.7.0 alpha 1**, на основе полученной 0.6.3.

- [План разработки для команды](docs/TEAM_DEVELOPMENT_PLAN_RU.md) — [PDF](dist/LifeSim_PMC_Team_Development_Plan_RU.pdf), [DOCX](dist/LifeSim_PMC_Team_Development_Plan_RU.docx)

- [Отчёт этапа 1: компания, роли и казна](docs/STAGE_1_COMPANY_TREASURY_RU.md)
- [История изменений](CHANGELOG.md)

Исходный код аддона находится в `addons/alspmc_core`, проверки — в `tests` и `tools`.
В `dist` сохранены предыдущие сборки и контрольные суммы. Исходный полученный
архив 0.6.3 сохранён без изменений в `baselines/0.6.3`; его хеш указан в `BASELINE.json`.
Оригинальный LifeSim и его ресурсы в репозиторий не включены.

Будущие механики в плане разработки не следует считать реализованными.
Проверки SQF и интерфейса не заменяют тестирование в Arma: полный перенос старого
набора регрессионных проверок на 0.6.3 ещё предстоит выполнить.

## Отчёт этапа: публикация в GitHub

Исходники, сборки, проектные документы и отчёты собраны в одном репозитории для
совместной разработки и независимой проверки. Добавлены этот указатель материалов
и контрольные суммы всех архивов и документов в `dist/SHA256SUMS.txt`.
Проверены целостность ZIP-архивов и совпадение хеша базовой сборки с `BASELINE.json`.
Игровой код на этом этапе не изменялся; повторный игровой тест не проводился.
