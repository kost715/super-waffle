# PMC Drugs — история изменений

## 0.1.0 alpha 1 — 2026-11-01

Первый этап по ТЗ «Pharmacological System for ACE3»: приоритеты 1 и 2.

- Stim1f (боевой стимулятор, автоинъектор 0,5 кг). Ввод через ACE-самовзаимодействие
  «Снаряжение → Ввести Stim1f», 2 с.
  - Актив 14 / 12 / 10 мин при весе снаряжения 20 / 40 / 70 кг; на это время множитель
    нагрузки (duty) ACE Advanced Fatigue 0,5.
  - При вводе запас AN заливается до максимума (2 300 ммоль).
  - Урон мышцам по таблице доз ТЗ распределяется равномерно по активу; при мельдонии
    каждый тик ×0,77 (мельдония пока нет, место для него готово).
  - Жажда ×3 во время актива (если загружен ACE Field Rations).
  - Ввод во время выплаты долга разрешён: новый актив, долг сверху.
  - Ввод во время актива — передозировка: пульс через лекарство ACE +200 уд/мин с
    разгоном 30–50 с, при >220 ACE останавливает сердце. Актив продолжается, урона,
    долга и forceWalk от передоза нет. Без ACE Medical — потеря сознания и смерть через
    60–120 с.
- Модель нагрузки: один множитель для ACE на все препараты, min(снижающие) × max(повышающие).
- Долг: копит только активный источник (самый сильный снижающий препарат),
  400 Вт × max(повышающие) × (1 − его нагрузка) / anWattsPerATP × 0,5 в секунду.
  Выплата из запаса AN: сначала долг Stim1f (4,0 ммоль/с), потом Фенотропила (2,5),
  только когда источник не активен, не ниже порога (настройка CBA, 30–50%, по умолчанию 40%).
- Состояние хранится на теле игрока, только на его машине; новое тело начинается с нуля.
- Модуль Зевса «Износ мышц» на игрока: «Проверить» (значение скрыто до проверки) и
  «Установить» (0–1). Игрок видит одну нейтральную строку без чисел.
- Проверки в SQF-VM: 21.
