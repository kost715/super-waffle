# Самостоятельный PMC — техническая основа

Целевая кампания: **ровно две ЧВК, до 16 игроков**, синяя/WEST и красная/EAST,
правительство на стороне синих, общий зелёный противник. Четыре варианта базы
для каждой компании выбираются хостом перед началом кампании.

- [Актуальный вектор](../docs/standalone/DEVELOPMENT_DIRECTION_RU.md).
- [Дорожная карта](../docs/standalone/ROADMAP_RU.md).
- [Правила сторон и стартовой настройки](../docs/standalone/FACTIONS_AND_SETUP_RU.md).
- [Макет интерфейса](../docs/standalone/ui-preview/README_RU.md).

В этом каталоге сохранён **технический стенд S1** (текущая сборка 0.1.2 alpha 1 с миссиями внутри мода;
исправления по [аудиту](docs/AUDIT_0.1.1_RU.md)), подготовленный
до окончательного выбора двух компаний. Его три миссии 1/2/3 PMC исследуют
отношения сторон и не задают состав будущей кампании. Восемь баз, правительство,
полноценная экономика и новое меню в игровой сборке ещё не реализованы.

Инструкции стенда: [README_RU.md](README_RU.md). Они описывают именно S1.
Исходники и выпущенные ZIP сохранены без изменения, чтобы их можно было сравнить
с прежними проверками. Новый игровой функционал должен получить новую версию.
Программные проверки не заменяют пока не выполненный игровой прогон Arma.
