# S1 — самостоятельный каркас и стенд дипломатии

Дата: 26 октября 2026 года. Версия: **0.1.0 S1 alpha 1**.

## Что сделано и почему

Создан отдельный исходный каталог `standalone/`, собственный PBO `pmcs_core`,
пространство функций `PMCS`, нативная консоль Arma и три стартовые миссии Altis.
Варианты рассчитаны на одну, две и три ЧВК и по 16 игровых слотов. Это позволяет
проверять выбранный масштаб до переноса экономики и контрактов.

Запуск не использует LifeSim, CBA, ACE, ACRE, фракционные пакеты или веб-контрол
оригинала. Мод активируется только сценарием с собственным флагом. Совместная
загрузка LifeSim в данном стенде отклоняется с сообщением; прежний аддон остаётся
отдельной исторической сборкой.

В лабораторной модели компании назначаются по стороне игрового слота; во время
одной сессии сервер помнит UID участника и обнаруживает несовпадение стороны
после возрождения/переподключения. Настоящие создание ЧВК, приглашения и роли
относятся к следующему этапу.

Хост/администратор через ноутбук меняет симметричные отношения выбранной пары,
возвращает общий нейтралитет, включает Alpha против Bravo и восстанавливает
тестовых НПС. Остальные игроки наблюдают серверное состояние. Проверяются реальный
отправитель, администраторские права, зарегистрированный ПК и расстояние.

Идентификаторы сессии и запросов строковые. Изменение требует актуальной ревизии;
повтор того же пакета возвращает прежний результат, другой пакет со старой
ревизией отклоняется. Кэш результата ограничен, но удаление старой записи не
разрешает выполнить старое изменение: его ревизия уже неактуальна. Перезапуск
меняет сессию. Состояние отправляется адресно запросившему игроку. Для сервера игрока также
поддержана доверенная локальная доставка; обычный клиент эту ветку использовать
не может.

На полигоне — по два ИИ каждой ЧВК и два нейтральных жителя. При одной/двух
ЧВК независимый противник мира начинает бой только по отдельной кнопке; по
умолчанию старт мирный. Таблица показывает также реальные значения `getFriend`
в обоих направлениях, которые нужно сопоставлять с наблюдаемым поведением. ИИ не двигаются,
имеют фиксированный положительный рейтинг и используют штатный выбор целей.
Скрипты не заставляют их стрелять через `doFire/doTarget`. Это ограниченный
тест отношений, а не проверка обычного патруля или всего будущего боя.

Сброс удаляет только собственных тестовых НПС/группы и создаёт новый набор.
Частичный сбой создания отражается в подтверждении, ревизии и RPT.
Игроки, их группы и общие объекты миссии не входят в список удаления.

## Архитектурное ограничение, которое показывает стенд

Кандидат «одна боевая сторона на компанию» оставляет `civilian` нейтральным.
При одной/двух ЧВК можно выделить ещё одну сторону мировому противнику — группа
создаётся. При трёх компаниях свободной боевой стороны нет. Стенд явно сообщает
это и не подменяет независимого врага одной из компаний или мирными жителями.

Следовательно, отношения трёх ЧВК можно исследовать этим распределением, но оно
ещё не покрывает одновременно независимых бандитов, армии, полиции и компаний.
Нужен отдельный выбор/проверка модели мира после игровых результатов. Наличие
трёх записей компаний само по себе не считается решением произвольной дипломатии.

## Проверки и их границы

Выполнен синтаксический разбор 18 SQF-файлов и шести конфигураций миссий.
Для корневых полей SQF-VM использует обёртку конфигурации; исходные файлы
миссий не меняются. Это проверка грамматики, а не загрузки Eden/Arma.
Пройдены 69 целевых утверждений и шесть проверок пакета, включая побайтное
восстановление готового архива из поставляемых исходников.

Журналы сохраняются в `reports/`. Команды:

```sh
python3 tools/build.py
python3 -m unittest discover -s tests -p 'test_*.py'
python3 tools/check_sqf.py --vm /path/to/sqfvm
```

Проверки должны охватывать независимость сборки, формат трёх миссий, локализацию,
упаковку и воспроизводимость, матрицу отношений, защиту запросов и очистку.
Используется собственная модель недоступных SQF-VM операторов. Реальные стрельба,
видимость, локальность групп, RPT при загрузке миссии, графика диалога, JIP и
производительность подтверждаются только игровым прогоном.

**Arma в этой среде не запускалась. Независимого аудита Claude не было.**
Список реальных игровых действий — `GAME_CHECKLIST_RU.md`. Пакет предназначен
для передачи исходников на проверку, затем для тестирования пользователем.

## Что не добавлено на этом этапе

Постоянная БД, казна, приглашения, экономика, контракты, наём постоянных бойцов,
поставки, регионы и импорт старых сохранений. Игровой код 0.7.0 не изменялся.
Нагрузочный сценарий на 192 наёмника и сторонние моды пока не проверяются.
