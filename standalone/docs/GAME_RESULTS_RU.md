# Результаты игровых прогонов S1

Сюда записываются только результаты, реально полученные в Arma 3.
Сборки не меняются; пункты ссылаются на [игровой чек-лист](GAME_CHECKLIST_RU.md).

## S1 0.1.2 alpha 1 — первый прогон

- Дата записи: 26 октября 2026 года. Источник: сообщение пользователя.
- Сервер игрока (хост), моды: только `@PMC_Standalone`. RPT не сохранён.

| Что проверено | Результат |
| --- | --- |
| Миссия из мода появляется в списке и запускается (`CfgMissions`) | Работает |
| Появление игрока у лагеря | Работает |
| Ноутбук и тестовая консоль открываются | Работает |
| Смена отношений через консоль | Работает штатно (по наблюдению пользователя) |
| Сброс тестовых НПС | Работает |

## Ещё не проверено

- Вход второго игрока в идущую игру (исправление 0.1.1: никого не переносит к
  лагерям) — пункт 1 чек-листа, нужен второй клиент.
- Выбор целей ИИ по отношениям, подтверждённый логом: без RPT нет строк
  `[PMCS S1]` о гибели тестовых бойцов и сменах ревизий — пункты 2–4.
- Конкурентные изменения двумя администраторами, отказ обычному игроку,
  выход за 4,5 м от ноутбука — пункты 7–9.
- Возрождение, переподключение, перезапуск миссии — пункты 11–12.
- Выделенный сервер.

Следующий прогон: сохранить RPT (`%LOCALAPPDATA%\Arma 3\*.rpt`) и по возможности
подключить второго игрока.
