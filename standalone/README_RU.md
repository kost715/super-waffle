# PMC Standalone — 0.2.0 S2 alpha 1

**Новое в 0.2.0: стенд стейт-машины S2** по документу Override. Миссия
«PMC Standalone S2 - state machine» (Altis, 8 слотов): игроки начинают
гражданскими, каждый в своей группе с двумя ботами; боевая сторона назначается
по контракту при входе в зону БД, держится аурой, маскировка — стороной CIV или
флагом пленного, выстрел в тылу демаскирует. Тестовые посты ИИ измеряют, через
сколько секунд после смены стороны по группе начинают и прекращают стрелять.
Отчёт — [docs/S2_REPORT_RU.md](docs/S2_REPORT_RU.md), проверка в игре —
[docs/S2_CHECKLIST_RU.md](docs/S2_CHECKLIST_RU.md). Миссии S1 ниже не изменились.

## S1 (0.1.2)

Изменения 0.1.2: **тестовые миссии встроены в мод** (`CfgMissions`), отдельная папка
`MPMissions` больше не нужна. Формат `mission.sqm` приведён к виду, который
загружается из мода (поля `addons[]`, `AddonsMetaData`, `randomSeed`, обычные
маркеры-иконки). Игроки при старте появляются на маркере своей стороны и
ставятся движком на землю, поэтому высота рельефа в точке слота больше не важна.

Исправления 0.1.1 по аудиту: вход игрока в идущую игру больше не перемещает
остальных к лагерям; сборщик сохраняет хеши прежних релизов; список отношений в
консоли не мерцает; сторона погибшего тестового бойца в RPT записывается надёжно.
Подробности и найденное без исправления — [docs/AUDIT_0.1.1_RU.md](docs/AUDIT_0.1.1_RU.md).

Самостоятельный технический прототип Arma 3. Проверяет запуск, собственную
консоль и отношения игроков/ИИ. Игровой кампании, контрактов, казны и постоянного
сохранения в этом выпуске ещё нет.

## Установка и запуск

1. Закройте Arma 3. Отключите LifeSim и прежний LifeSim PMC.
2. Из готового ZIP поместите `@PMC_Standalone` рядом с локальными модами Arma 3.
   Включите эту папку через лаунчер. CBA, ACE, ACRE и пакеты фракций не требуются.
3. Миссии устанавливать не нужно: они внутри мода. Если от версии 0.1.0/0.1.1
   остались файлы `PMCS_S1_*.Altis.pbo` в папке `MPMissions` игры, удалите их,
   чтобы в списке не было двух копий. На выделенном сервере достаточно
   `-mod=@PMC_Standalone`. Мод нужен также всем клиентам. Сторонние моды
   добавляйте после базовой проверки.
4. «Играть → Сетевая игра → Создать сервер», карта Altis, одна из миссий
   `PMC Standalone S1 - 1/2/3 PMC`. Всего в каждой миссии 16 игровых слотов.
5. Выберите слот нужной компании: Alpha / Bravo / Charlie. У невыбранных слотов
   ИИ отключён. На выделенном сервере для управления тестом войдите администратором
   штатным способом. Хост сервера игрока получает право автоматически.
6. Рядом с местом появления найдите стол с ноутбуком и действие тестовой консоли.
   Обычный участник наблюдает состояние; хост/администратор меняет отношения.

Начальная модель — нейтралитет всех компаний и группы мира. На полигоне севернее лагерей
создаются по два вооружённых ИИ каждой ЧВК и два безоружных нейтральных жителя.
При одной/двух ЧВК отдельный тест мирового противника включается кнопкой
консоли. Это позволяет сначала спокойно открыть интерфейс и проверить нейтралитет.
Места лагерей и поля проверки отмечены на карте. Смена стороны через Zeus или
сторонние скрипты в базовом прогоне не используется.

## Что проверять

В консоли выберите две компании и задайте нейтралитет или вражду. Кнопка
«Alpha против Bravo» оставляет Charlie нейтральной. Сброс восстанавливает тестовых
НПС и нейтралитет; игроки не удаляются и не перемещаются. Корпоративные отношения
симметричны. В строках таблицы дополнительно показаны два фактических значения
`getFriend`: 1/1 — дружелюбие сторон, 0/0 — враждебность. Само наличие этих чисел
не доказывает правильный выбор цели и стрельбу. Боевые приказы `doTarget/doFire` не подменяют поведение ИИ.

Вооружённые ИИ стоят на месте, чтобы упростить наблюдение стрельбы. Их рейтинг
зафиксирован положительным: тест изолирует отношения сторон от смены статуса
«изгой». Игрокам рейтинг и сторона скриптом не переписываются. Изменения и смерти
тестовых НПС пишутся в RPT с префиксом `[PMCS S1]`.

Полный сценарий проверки — [docs/GAME_CHECKLIST_RU.md](docs/GAME_CHECKLIST_RU.md).
Отчёт этапа и границы модели — [docs/S1_REPORT_RU.md](docs/S1_REPORT_RU.md).

## Ограничение трёх компаний

Исследуемая модель выделяет каждой компании одну боевую сторону Arma,
а `civilian` сохраняет для мирных жителей. В миссиях на одну/две ЧВК свободная
боевая сторона используется отдельной группой противника мира. При трёх ЧВК
свободной стороны нет: такой противник не создаётся, консоль сообщает ограничение.
Третья ЧВК не объявляется автоматически врагом мира.

Это кандидат модели для исследования, а не объявленное решение всей дипломатии
будущей кампании. Независимые отношения нескольких фракций мира вместе с тремя
ЧВК остаются открытым архитектурным вопросом. Игровые результаты нужны до выбора
окончательной модели. Произвольное число фракций и 192 наёмника этим стендом
не проверяются.

## Сборка и независимая проверка

В архиве исходников нет функций и ресурсов LifeSim. Из корня исходников:

```sh
python3 tools/build.py
python3 -m unittest discover -s tests -p 'test_*.py'
python3 tools/check_sqf.py --vm /path/to/sqfvm
```

Сборщик создаёт один мод и три тестовые миссии. Для программных проверок не нужен
распакованный LifeSim. Запуска Arma и независимой проверки Claude в этой среде
не было. Пользователь передаёт исходники на аудит самостоятельно.
